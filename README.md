# MAKE ENTRY

엔트리 작품을 모아 소개하고, 완성된 프로젝트 파일(`.ent`)을 다운로드할 수 있도록 구성하는 프로젝트입니다.

## 현재 상태
- 반응형 메인 페이지 구성 완료
- 작품이 없을 때 빈 상태 안내 표시
- 추후 작품별 `작품이름/index.html` 다운로드 페이지를 추가할 예정
- 각 작품의 완성본 `.ent` 파일은 작품별 폴더에 함께 보관할 예정

## 작품 추가 방식
작품이 준비되면 메인 페이지의 작품 목록에 연결하고, 작품 폴더에 소개 및 다운로드 페이지와 완성된 `.ent` 파일을 추가합니다.
